On the basis of the State of Art, the following requirements have been made:

\begin{itemize}
    \item The bracelet should be able to detect falls (problem statement)
    \item The system should be able to send notifications to the users relatives, if a fall is detected (State of art (Sensorem and Cekura)) 
    \item The bracelet should be waterproof, to limit the scenarios in which it should be taken off  (State of art (Sensorem))
    \item The bracelet should run on a rechargeable battery (State of art (Sensorem))
    \item The bracelet should be able to detect inactivity, within set time intervals (State of art (Sensorem))
    \item The users relatives should be able to see the users GPS location (State of art (Sensorem, Sensio and Cekura))
    \item  The bracelet has to have an emergency button, so the user can notify their relatives if they are feeling unwell or an emergency has occurred (State of art (Sensorem, Sensio and Cekura))
    \item The product needs to be easy to use, because there is no requirement for the user to have any technological knowledge (Introduction (Ældre-sagen))
    \item The battery needs to hold power for at least 1 day without recharging (State of art (Sensorem and Smart watches))
    \item The user should be able to add relatives to the notification list in the application (State of art (Sensorem and Cekura))
    \item The application needs to be in Danish (Introduction)
\end{itemize}
