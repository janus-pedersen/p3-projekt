\subsection{Requirements}
Based on the background and state-of-the-art section, a couple of requirements were made. These outlined the product and the accompanying system. Afterwards, in the problem analysis section, the final requirements were made. Those requirements drew from the UML diagrams, such as context and deployment diagram. Which was used to create an overview of the system, its ability, the hardware parts and how it all fit together. 

\subsection{System architecture}
In terms of system architecture, a choice had to be made in terms of hardware. Based on the collective knowledge and idea of what the product should be able to do, there was a need for the microcontroller to have Bluetooth and an accelerometer. Furthermore, there was a wish for an all-in-one product, so that the final product would be small in size. The need for it to be small was because the vision of the product being a wristband was already there. This is why the microcontroller ESP-32 C6 dev board was chosen. This, along with a 3.3-volt battery, concludes the hardware. For the software, the Arduino IDE was used along with C++ code for the microcontroller, whereas for the application, VS Code with Typescript using the React framework was used.
