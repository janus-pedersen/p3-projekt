\subsection{User tests}
To tests the usability of the system, a complete suer test was conducted. Testing how easy it was for brand new users to perform simple actions in the app and system. 

\subsubsection{Test setup}
For each user test, the chosen user was asked to complete a list of tasks, both in the app as well as with the physical hardware. The list of tasks is as follows.

\textbf{As the wearer}
\begin{itemize}
    \item Sign in with a given phone number
    \item Navigate to the profile page and edit your username
    \item Switch to the \verb|Wearer| view
    \item Connect the device to the app
    \item Add a given phone number and name to the contacts list
    \item Trigger a manual alert via the wristband    
\end{itemize}

\textbf{As the guardian}
\begin{itemize}
    \item Sign in with a given phone number
    \item Switch to the \verb|Guardian|
    \item Check the map to locate a given relative
    \item Check the alerts page, to check up on any alerts
\end{itemize}

After each of the tests, each participant was asked the following questions.

\begin{itemize}
    \item What are your thoughts on the overall usability and experience of the system?
    \item What do you think of the wristband's design and function?
    \item What did you think of the user experience / design of the app?
    \item Did you encounter any road bumps or issues in your time using the system?
\end{itemize}

\subsubsection{Test results}
From the tests, a couple of road bumps and issues were identified. For one, the user had no way of knowing that the manual alert button requires a long press, and not just a \textit{click}. This however can be explained by the fact that for a real product release, information like that would be described in the accompanying written user-manual. With a \textit{recreation} of such manual, the following user tests went without that issue.

Overlooking some of the minor things like the signal strength for the device being displayed as a number next to the name of the device when connecting, it all went smoothly. The users were able to complete all the task in about 2 minutes, and all reported it being surprisingly easy.
