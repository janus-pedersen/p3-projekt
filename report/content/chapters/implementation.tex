\section{Implementation}
This section describes the implementation of the Lapsus fall detection system based on the design decisions and requirements defined in the previous sections. The purpose of the section is to demonstrate how the conceptual design has been translated into a working prototype consisting of embedded firmware, a mobile application, and supporting backend services.

The implementation is divided into two main parts. First, the firmware implementation of the wristband is presented, including sensor configuration, fall detection logic, and Bluetooth Low Energy communication. Second, the implementation of the mobile application and its integration with cloud services is described, focusing on user interaction, data handling, and alert distribution.

Throughout the section, emphasis is placed on how the implementation fulfills the defined functional and non-functional requirements. Key technical choices, such as the use of threshold-based fall detection and cloud-based backend services, are justified in relation to constraints on power consumption, reliability, and usability.

The implementation described in this section results in a functional prototype that demonstrates the feasibility of the proposed system and forms the basis for subsequent testing and evaluation.
