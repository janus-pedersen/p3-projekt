\section{Design}

In order to gain an overview of the solution, the following section was made. In which the design process and requirements set an outline for the system. This outline is then visualised through a context diagram. Therafter the user roles are expanded in the user stories and the corresponding use case diagram. Futhermore, the design of the wristband and 3D print design and the accompanying thought proces is argumented and explained. In addition to the physical elements of the solution, the application, its interface and infrastructure is explained and guided with a data flow diagram and a sequence diagram to show the innerworks of the code as well as a specific scenario. In the end a deployment diagram shows how the physical and in-cloud element connect and work intertwined.
